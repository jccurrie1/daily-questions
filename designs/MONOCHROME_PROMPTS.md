# Mononote palette edit prompts

Historical source only. Superseded by the [current MVP designs](README.md). Any Today screen, Delete control, editable saved answer, or multiweek summary shown here is outside the current MVP.

Tool: built-in imagegen. Inputs are the previously edited local designs. These prompts produced the neutral palette images used before the approved character logo was applied. See [logo application prompts](LOGO_APPLICATION_PROMPTS.md) for the current gallery images.

Palette reference: https://www.digitalminimalist.com/tools/mononote

## menu-bar

Input: `menu-bar-minimal.png`

Output: `menu-bar-monochrome.png`

Use case: precise-object-edit. The input image is the EDIT TARGET. Recolor this existing Daily Questions macOS screenshot to a Mononote-inspired neutral light palette. Preserve the exact screen layout, spacing, geometry, typography, all wording, all data, graph shapes, question rows, selected states, functional controls, and full-screen framing. Change application-owned colors only. Palette: main application background #F5F5F5, cards and fields #FAFAFA, primary text and primary action fills #1A1A1A, secondary text and inactive icons #666666, subtle borders and tracks #DEDEDE, pale selected-row fill #E5E5E5, white text on black filled buttons. Replace EVERY blue application accent with charcoal or gray, including filled buttons, question answer selections, sidebar highlight, selected row indicator, progress rings, chart bars/lines/areas, tiny chart dots and table check circles. Replace green application badges and icons with grayscale. Active sidebar row should be pale gray with black icon and text. Neutral secondary controls, including Delete, remain gray with dark text. The app logo retains its white sunrise glyph and rounded-square shape but its blue background becomes charcoal; also recolor the Daily Questions app icon in the macOS Dock and its menu bar icon where shown. Use opaque or nearly opaque neutral surfaces so wallpaper colors do not tint the app UI. Preserve subtle depth, borders, and native macOS feel. Red is for app errors only; this screen has no error, so no red application content. Keep native macOS traffic-light window controls in their standard colors, and preserve ALL desktop wallpaper colors and OTHER APPS icons in the Dock, the operating-system menu bar, time/date, desktop composition. No new copy, features, logos, illustration, captions, slogans, motivational text, or streaks. Crisp legible UI. The menu bar popover keeps its current question list and factual footer. The active status-item background should be neutral charcoal instead of blue.
